# Design Spec — целостность обратной связи

- **Автор / ответственный:** rsidorenko
- **Дата:** 2026-09-20
- **Статус:** approved
- **Связанный plan:** `docs/superpowers/plans/2026-09-20-feedback-integrity.md`

## Контекст и проблема

`trial_feedback` различает ответы по пользователю, типу и платформе, но не по поверхности. Web-ответ с `/check` способен заменить Telegram-ответ того же пользователя и стереть route-контекст. Frontend `/check` показывает экран благодарности даже при ошибке API. В Telegram «Пропустить» в опросе неоплаты уводит в главное меню вместо возврата к тарифам. В holdout-таблице два одинаковых React key `Оплатили` создают предупреждение и нестабильный reconciliation.

## Цели

- Хранить Telegram- и web-feedback независимо.
- Показывать surface в аналитике админки.
- Не подтверждать пользователю сохранение feedback при сетевой/API-ошибке.
- Возвращать пропуск nonpayment-опроса к тарифам.
- Устранить дублирующиеся React keys.

## Non-goals

- Не менять список закрытых причин и тексты уведомлений.
- Не собирать свободный текст.
- Не менять оплату, trial lifecycle или VPN-доступ.

## Предлагаемое решение

Добавить `trial_feedback.surface` со значениями `telegram|web`, безопасно backfill-ить существующие web-строки по пустому connection route и заменить уникальность на `(internal_user_id, feedback_type, platform, surface)`. Recorder получает явный surface, валидирует сочетание surface/type/context и upsert-ит только внутри одной поверхности. Admin API добавляет surface breakdown.

Frontend сохраняет текущий экран и показывает retryable error, если feedback API не ответил успешно. Telegram skip использует существующий `CB_BUY_VPN`. Заголовки holdout получают уникальные названия.

## Влияние

- **Миграции БД:** additive/backfill migration `097`, старые ответы не удаляются.
- **Биллинг/VPN:** без изменений.
- **Приватность:** только enum surface, новых персональных данных нет.

## Критерии приёмки

- [ ] Web и Telegram ответы одного пользователя существуют одновременно.
- [ ] Повторный ответ заменяет только ответ той же surface.
- [ ] Admin API/UI показывает surface breakdown.
- [ ] Ошибка feedback API не приводит к ложному «Спасибо».
- [ ] Skip возвращает к тарифам; React key warning устранён.
- [ ] Backend/frontend/PG тесты зелёные.
