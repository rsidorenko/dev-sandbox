# Срезы рекламного кабинета Telegram Ads

- Дата: 2026-09-25
- Статус: approved — пользователь поручил внести данные и автономно реализовать улучшения.
- План: `docs/superpowers/plans/2026-09-25-telegram-ads-snapshots.md`

## Контекст и цели

Предоставлены четыре скриншота 20 объявлений с накопительными показами, кликами,
действиями, расходом, остатком бюджета, ставкой CPM, статусом и датой в кабинете.
Пользователь подтвердил стоимость покупки 1 TON = 1,34 USD. Дата среза, курс RUB
и назначение двух денежных строк androidinsider_ru не подтверждены.
Существующий `PostgresTelegramAdsSpendRepository.set_daily_spend` принимает только
рубли за конкретный день. Запись накопительного расхода сюда исказит отчёт.

## Решение

Отдельный неизменяемый срез с уникальным source_ref, временем внесения, необязательной
датой наблюдения, подтверждённым курсом USD/TON и массивом объявлений. Денежные значения
передаются строками, валидируются Decimal; исходные составные строки сохраняются.
Повтор идентичного импорта идемпотентен, изменение того же source_ref возвращает 409.
POST защищён admin auth и CSRF, GET отдаёт последний внесённый срез.
Админка показывает отдельную таблицу независимо от фильтра периода, явную дату/её отсутствие,
TON и USD, остаток отдельно от расхода, предупреждения о неопределённостях.
Неподтверждённые start-метки не реконструируются; действия кабинета не считаются оплатами.
Общие суммы считаются из видимых строк; неясные компоненты помечаются для проверки.

## Влияние и границы

Аддитивная миграция 104, новые admin API и компонент статистики, данные скриншотов
в JSON с хешами исходных файлов. Пользовательские платежи, VPN, ключи и уведомления
не меняются. Никакого автоматического пересчёта RUB, распределения по дням, запуска рекламы.
Альтернатива дневной RUB записи отвергнута из-за отсутствующих исходных данных.

## Приёмка

- 20 объявлений сохраняются без повторного начисления при повторе импорта.
- Отсутствующий курс RUB и дата наблюдения честно обозначены; обе денежные строки сохранены.
- Валидация чисел/дубликатов, auth/CSRF, конфликт и реальная БД покрыты тестами.
- Полный pytest, ruff, frontend test/typecheck/lint, зелёный CI, review, merge, smoke VPN.
