## Контекст и проблема

Лендинг одновременно продаёт «свободный интернет», доступ к YouTube/Instagram и защиту Wi-Fi —
три разных смысла, главный оффер теряется. Часть формулировок юридически рискованна («перехват
невозможен» — абсолютное обещание безопасности; «Доступ к сервисам без ограничений»). «3 дня
бесплатно» спрятан вторым CTA. Два блока «как работает» дублируют друг друга. Число устройств
несогласовано («от 1 до 20» в FAQ vs «от 5 до 20» в преимуществах). Цель слайса — репозиционировать
лендинг как защищённое соединение, усилить конверсию в пробный период, убрать рискованные формулировки.

## Цели

- Один главный тезис: «Защищённое соединение без сложных настроек».
- «3 дня бесплатно» — главный CTA (hero и финал).
- Убрать юридически рискованные/абсолютные формулировки.
- Устранить дублирование «как работает».
- Согласовать число устройств (единый источник правды в `siteConfig`).
- Добавить блок доверия (trust-bar) и 4 ключевых FAQ (пробный / после пробного / несколько устройств / автопродление).

## Non-goals

- Не меняем тарифную сетку и отображение цен (B2).
- Не добавляем отзывы (B3 — нет данных) и блок use-cases (B4).
- Не трогаем `ReferralSection.tsx` (его текст зависит от будущей семантики C1).
- Не меняем trial-логику бэкенда; только текст/CTA.

## Текущее состояние

Читать реальные файлы (композитор и виджеты):
- `frontend/src/app/(site)/page.tsx` — порядок: Hero → Features → HowItWorks → Tariffs → Referral → Delivery → FAQ → Cta.
- `frontend/src/widgets/landing/HeroSection.tsx` — badge «Доступ к сервисам без ограничений», H1 «Свободный интернет», subtext «YouTube и Instagram, … банки … за границей»; CTA: «Выбрать тариф» (primary), «🎁 3 дня бесплатно» (secondary).
- `frontend/src/widgets/landing/FeaturesSection.tsx` — «перехват невозможен»; карточка «Доступ к сервисам без границ»; «от 5 до 20 устройств».
- `frontend/src/widgets/landing/HowItWorks.tsx` + `DeliverySection.tsx` — два почти идентичных 4-шаговых блока.
- `frontend/src/widgets/landing/CtaSection.tsx` — primary «Выбрать тариф» (#tariffs).
- `frontend/src/shared/config/site.ts` — `trialDays=3`, `refundDays=7`, `faq` (6 пунктов), `howItWorks` (4 шага); нет констант устройств.

## Предлагаемое решение

- **Hero:** badge → «Защищённое соединение»; H1 → «Защищённое соединение без сложных настроек»;
  subtext про защищённое соединение + устройства (без YouTube/Instagram/банков); **«🎁 3 дня бесплатно»
  (`/trial`) — главный CTA**, «Выбрать тариф» — вторичный; микрокопия доверия (возврат/оплата/активация).
- **Features:** «перехват невозможен» → «трафик передаётся по зашифрованному соединению, что снижает
  риск перехвата»; карточку «Доступ к сервисам без границ» заменить на «Поддержка без ожидания»
  (3 карточки: защита / устройства / поддержка); число устройств из `siteConfig.devices`.
- **HowItWorks/Delivery:** удалить `DeliverySection.tsx` (дубль), оставить `HowItWorks`; убрать из композитора.
- **CtaSection:** primary → «Попробовать бесплатно» (`/trial`), secondary «Выбрать тариф» (`#tariffs`).
- **site.ts:** добавить `devices: { base: 5, min: 1, max: 20 }`; добавить 4 пункта FAQ.
- **(новый) TrustBar:** узкая полоса под hero — «3 дня бесплатно · Возврат 7 дней · Карта + СБП · Поддержка».

## Влияние

- **Файлы:** `HeroSection.tsx`, `FeaturesSection.tsx`, `CtaSection.tsx`, `HowItWorks.tsx` (без изменений),
  удалить `DeliverySection.tsx`, новый `TrustBar.tsx`, `app/(site)/page.tsx`, `shared/config/site.ts`,
  `shared/config/site.test.ts`.
- **Бэкенд:** нет. Миграций нет. `domain/plans.py` не трогаем (B2).
- **Безопасность:** снижается юридический риск (убираем абсолютные обещания и «обход»-офферы).
- **Биллинг / retention / VPN-провайдер:** не затрагиваются.
