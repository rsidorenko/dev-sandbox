# Проверка права на выдачу VPN-ключей

- Дата: 2026-09-22
- Статус: reviewed
- Основание: поручение исправить подтверждённые дефекты аудита.
- План: `docs/superpowers/plans/2026-09-22-vpn-entitlement.md`

## Подтверждение

GET keys создаёт пользователя при ошибке чтения конфигурации. Web и Telegram
перевыпускают ключи без проверки действующей подписки и без передачи оплаченного
срока/лимита (провайдер по умолчанию включает 365 дней и пробный лимит).

## Решение

Общая чистая политика права на доступ: состояние active, ключи не удалены,
будущий срок trial либо оплаченной подписки. GET проверяет право и только читает.
Перевыпуск проверяет право до первого изменения и передаёт точный срок и лимит
из snapshot. Протокол create_user расширяется необязательным expires_at; старые
вызовы сохраняют поведение. Политика /sub/ использует тот же предикат.

## Границы и риски

Авторизация кабинета после истечения остаётся доступной для продления. Миграций
нет. Ротация UUID и межпроцессная сериализация — следующий отдельный фикс.
Право не проверяется безусловно внутри create_user: trial создаётся до snapshot.
Действующий trial и оплаченный тариф должны работать без изменения даты/лимита.

## Приёмка

Реальные HTTP-обработчики отклоняют expired/inactive/deleted и допускают trial/paid.
GET ни при какой ошибке не вызывает создание. Перевыпуск передаёт точные параметры.
Панель получает исходный Unix timestamp, не округлённое количество дней.
Полный pytest, ruff, release health check, review и CI перед merge.
