# Design Spec — Мобильные подсказки и блок качества админки

- **Автор / ответственный:** команда Bravada VPN
- **Дата:** 2026-09-20
- **Статус:** approved
- **Связанный plan:** `docs/superpowers/plans/2026-09-20-admin-mobile-tooltip-fix.md`

## Контекст и проблема

После адаптации статистики админки под мобильные устройства обнаружены две регрессии: открытая
по нажатию подсказка метрики остаётся на экране без ограничения времени, а длинные технические
значения в блоке «Качество и данные» расширяют страницу за пределы мобильного viewport.

## Цели

- Автоматически закрывать подсказку, открытую нажатием, через короткий читаемый интервал.
- Сохранять привычное поведение подсказки по hover/focus на десктопе и доступность с клавиатуры.
- Исключить горизонтальное переполнение карточек «Качество и данные» на узком экране.
- Зафиксировать оба сценария регрессионными тестами.

## Non-goals

- Не менять состав и расчёт метрик.
- Не менять API, БД, биллинг, VPN-провайдер или систему экспериментов.
- Не перерабатывать визуальный стиль всей админки.

## Текущее состояние

- `frontend/src/features/admin/MetricHelp.tsx` использует нативный `details`, который после tap
  остаётся открытым до повторного действия пользователя.
- `frontend/src/features/admin/QualitySection.tsx` содержит строки с `whitespace-nowrap` и длинные
  объединённые идентификаторы источников/кампаний, которые не переносятся на мобильном экране.
- `frontend/src/features/admin/MetricHelp.test.tsx` проверяет только переключение атрибута `open`.
- `frontend/src/features/admin/QualitySection.test.tsx` проверяет данные секции, но не её
  ограничения ширины и перенос длинных значений.

## Предлагаемое решение

`MetricHelp` станет управляемым клиентским компонентом. Нажатие фиксирует подсказку и запускает
таймер автозакрытия на 6 секунд; повторное нажатие, Escape и нажатие за пределами компонента
закрывают её немедленно. Hover и focus продолжают работать без таймера, пока указатель или фокус
остаются на контроле.

Для секции качества добавляются `min-width: 0`/`max-width: 100%` на контейнеры, перенос длинных
технических строк и вертикальная компоновка строки источника на узком экране. Таблицы сохраняют
собственный горизонтальный скролл вместо расширения всей страницы.

## Альтернативы

- Оставить `details` и закрывать его через DOM-таймер: хуже согласуется с React и усложняет
  корректное управление focus/hover.
- Закрывать только по повторному tap: не решает исходную проблему перекрывающей экран подсказки.
- Обрезать значения многоточием: скрывает важные диагностические идентификаторы.

## Влияние

- **Файлы:** `MetricHelp.tsx`, `QualitySection.tsx` и их тесты.
- **Миграции БД:** нет.
- **Безопасность:** без изменений.
- **Биллинг:** без изменений.
- **Retention / lifecycle:** без изменений.
- **VPN-провайдер:** без изменений.

## Открытые вопросы

- Нет. Интервал 6 секунд выбран как достаточный для чтения короткой справки и не блокирующий экран.

## Критерии приёмки

- [x] Подсказка, открытая tap/click, автоматически исчезает через 6 секунд.
- [x] Повторный click, Escape и click вне компонента закрывают подсказку сразу.
- [x] Hover/focus доступны на десктопе, кнопка сообщает состояние через `aria-expanded`.
- [x] «Качество и данные» не расширяет мобильную страницу; длинные значения переносятся.
- [x] Тесты покрывают автозакрытие и мобильные CSS-ограничения.
- [x] Frontend-тесты, lint, typecheck и build проходят; backend-регрессия и release health зелёные.
