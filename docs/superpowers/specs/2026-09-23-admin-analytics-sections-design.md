- **Plan:** `docs/superpowers/plans/2026-09-23-admin-analytics-sections.md`

## Решение
Существующий отчёт разделяется на «Продажи», «Активация и удержание», «Реклама», «Качество VPN». Сохраняются все шесть графиков, funnel/эксперименты, когорты/holdout, расходы и качество данных. Меняются представление и навигация, не формулы/запросы метрик. Общий период и выбранный раздел записаны в URL, back/refresh восстанавливают выбор. Смена раздела не перезагружает API и не теряет черновик рекламного расхода. ДатыМСК, источник/время получения и явное обновление. Невалидный URL безопасно нормализуется; гонки загрузок отсечены request-id. Ошибка API не подменяется нулевыми метриками.

## Приёмка
Непустые fixtures показывают все шесть графиков в правильных разделах. Период/диапазон/раздел переживают reload/back; черновик расхода сохраняется при переключении. Финансовые и аналитические расчёты backend неизменны. Frontend/build/e2e и backend regression зелёные.
