# Стартовый обзор сервиса

- **Дата:** 2026-09-23
- **Статус:** approved — автономная реализация поручена пользователем.
- **Plan:** `docs/superpowers/plans/2026-09-23-admin-service-overview.md`

## Решение
`/admin` становится обзором, а не перенаправлением в пользователей. Один read-only снимок БД: право на доступ по общей семантике entitlement, регистрации за сегодняМСК, внешние принятые RUB-оплаты за сегодня с исключением тестовых/накрученных/операторских, незавершённая выдача и ротация, активные инциденты и наблюдения серверов. Сигналы переиспользуются из `admin_attention`, без дублирования сетевых опросов.

Карточки ведут в подробные разделы; быстрый поиск — в пользователей. «Требует внимания» показывает первые 10 сигналов с приоритетом критических и полный счётчик. Есть источник, время получения, различение неизвестных/устаревших наблюдений. Успешное чтение БД не обозначает исправность всех клиентских туннелей.

## Ограничения
Выручка только RUB: subscription_activated/device_topup с неотрицательной или неизвестной суммой; произвольные события не считаются оплатами. Баланс не добавляется. Различие со старой формулой общей статистики подписано в интерфейсе. Оплаты с неизвестной суммой считаются отдельно. Операционный счётчик доступа включает тестовые аккаунты, а коммерческие показатели исключают их — это подписано. Нет провижининга, новых миграций или изменения VPN. Общий снимок выполняется в read-only repeatable-read транзакции.

## Приёмка
PostgreSQL проверяет trial/удалённые ключи, деньги/валюту/исключения, auth и отсутствие секретов. Browser smoke: overview как landing, ссылки, поиск, состояния unknown/error. Полные проверки, отдельныйMR и merge. После последнего деплоя — readonly production API smoke и фактический VPN end-to-end без ротации ключей/рестартов.
