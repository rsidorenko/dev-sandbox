# Статус выдачи после оплаты балансом

- Дата: 2026-09-22
- Статус: reviewed
- Основание: поручение исправить подтверждённые дефекты аудита.
- План: `docs/superpowers/plans/2026-09-22-balance-provider-result.md`

## Подтверждение

Четыре регрессионных теста падают до исправления. Реальный XuiVlessProvider
без серверов возвращает UNAVAILABLE, но `_ensure_vless_keys_atomic` считает
любой возврат без исключения успехом и сбрасывает признаки отключённых ключей.

## Решение

SUCCESS — единственный успешный исход. Остальные результаты проходят существующие
ограниченные повторы и компенсацию. Проверить create и activate, временный отказ
и отказ реального провайдера без серверов. Отсутствующий/неверный результат также
не считать успехом. Не менять условия списания, тарифы или политики возврата.

## Риски и границы

Исправление делает доступным существующий путь компенсации для типизированных
отказов. Его конкурентность и восстановление после рестарта — отдельная задача.
Нет миграций и изменений UI. Проверки: новые тесты сначала красные, затем зелёные;
полный pytest, ruff, release health check, независимое review, CI перед merge.
